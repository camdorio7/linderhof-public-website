# Linderhof Country Club public website

Kernwood-inspired editorial redesign, independently branded for Linderhof. Next.js app with Membership, Golf, Pool & Amenities, LPOA, News & Events and LINDEX member sign in. Shop and Stripe checkout removed.

## Deployment
Upload project contents to the GitHub repository root, then deploy with Vercel using the Next.js preset.

## Before launch
Replace all illustrative Unsplash photography with approved real club images; replace temporary L monogram with approved crest; review official membership and policy copy; confirm links. No changes to LINDEX or Supabase are required.
