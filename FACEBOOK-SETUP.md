# Linderhof Facebook feed

The News & Events page is configured to show the official public timeline:
https://www.facebook.com/LinderhofCountryClub/

The feed uses Meta's Facebook Page Plugin iframe. It does not need API credentials, Resend, Instagram, or environment variables.

**Important:** Facebook controls whether a page and its posts can be displayed in an iframe. Public page visibility, country/age restrictions, browser tracking protection, and visitors' Facebook settings can affect rendering. The website always includes a direct link to the official Facebook page.

Deploy to Vercel and check /events on desktop and mobile. If the feed is blocked, use the direct Facebook link. Do not paste a Facebook login password or access token into the website source.
